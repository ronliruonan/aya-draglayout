# aya-draglayout v2 范围与验收

## 基线

从旧版 master 的 `2c39de3` 开始，开发分支为 `codex/v2`。旧版 Vue 2 代码、根依赖与 docs 构建产物保持独立；新应用在 apps/v2，构建输出为 apps/v2/dist。v2 初期是可嵌入、页面 JSON 驱动的布局编辑器与渲染器，不做完整低代码平台，不发布六个独立 npm 包。

## M0：基础渲染

- 独立 Vue 3 / TypeScript / Vite 工程。
- version=1 的纯数据页面协议；文本、指标卡与递归容器。
- 运行时严格校验，限制输入规模、节点数、深度并检查重复 ID。
- 固定组件注册表、默认属性、只读 renderer。
- 桌面示例预览与页面 JSON 查看。按用户要求不考虑移动端适配。
- 验收：类型检查、生产构建、协议测试通过；正常页面可渲染，无效输入被拒绝；桌面常用窗口宽度下无横向溢出。

## M1：编辑闭环（尚未实现）

新增、删除、移动、属性修改、JSON 导入导出、撤销重做统一经 core 命令。验收：编辑、导出、清空、导入恢复；撤销重做保持数据一致；非法导入不破坏当前页面。

## M2：可选 AI（尚未实现）

## M1 实施范围

- 桌面三栏编辑界面：组件库、画布、属性面板。
- 通过 core 命令添加、删除、同级排序、跨容器移动、修改属性和页面名称。
- SortableJS 模拟拖拽与嵌套容器放置区；同时提供点击添加和上/下移动按钮。
- 预览使用 M0 PageRenderer；编辑画布显示选择框和拖拽手柄。
- JSON 文本校验导入、JSON 文件导出；清空/替换/属性修改均可撤销重做。
- 失败的操作不能改变当前页面或历史；新编辑清除 redo 分支。
- 内存历史最多 100 步，不自动保存至浏览器或服务器，刷新前需导出。
- M1 不包含旧版数据迁移、文件直接上传导入、AI 与持久化服务。

## M1 整改

界面按旧版简洁工具风格调整。保留文本、指标卡、容器，新增旧版样例提示、计时器和 CMD 加载挂件。协议版本仍为1，旧v2导出可导入。动画运行状态不进入JSON，挂载时启动、卸载时清理，重新挂载从初始状态开始。拖拽采用与旧版同源的 SortableJS，forceFallback 模式；嵌套容器用命中保护防止外层抢占落点。

## 布局入口调整

容器从组件区移出，界面称为“布局区域”。通过画布工具栏添加单列、双列或三列布局，复用 core insert 命令及撤销重做。组件区展示5个内容挂件；底层 container 协议及默认示例布局保持兼容。
